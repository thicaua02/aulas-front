Media Queries - Desktop First

Conceito

Media Queries são regras especiais que criamos alterações na página de acordo com determinadas condições (exemplo: tamanho da tela).

Essas alterações ocorrem quando a configuração de breakpoints.

As medias queries são aplicadas de acordo com a estratégia usada para design responsivo, podendo ser:

  • Desktop First: do pequeno para o grande
  • Desktop First: do grande para o pequeno
